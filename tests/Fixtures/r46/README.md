# Frozen r46 input

These gzip files are immutable test inputs, not test output. They contain synthetic
data generated by Megalopolis **r46** (`dff38a8ab25b758e8bb7ea1a621cf33983e9e54e`)
under PHP **5.2.5**, SQLite and MySQL **5.7.44**. Generator and export instructions:
[`compat/php52/README.md`](../../../compat/php52/README.md), generator commit
`a211aa9`. The uncompressed SHA-256 values were recorded before this suite existed
in [`large-fixtures.sha256`](../../../compat/php52/large-fixtures.sha256).

100 subjects × 100 works; 400 text/HTML combinations. Supplementary Unicode is
included in SQLite; the MySQL `utf8` corpus uses BMP alternatives. The two backends
are intentionally not byte-identical. TSV hashes were calculated **before insertion**
and independently checked against stored rows. Hash framing is `N;` for null,
`S<byte length>:<bytes>;` for a string, in this order: title, name, summary, body,
afterword, three ordered tags. Empty strings and nulls must not be conflated.

Do not regenerate these fixtures when changing the application or its schema.
New historical versions belong in new fixture directories with new provenance.
Tests restore separate disposable copies for baseline and candidate, since even
GET requests increment read counts. No real accounts, secrets or user content.
